TRAVIO - AI Bus Recommendation System

Features:
- Live bus search using AbhiBus API
- AI-powered bus recommendation
- Fare prediction model
- Real-time seat availability
- Route search
- Dataset collection for training

Tech Stack:
- Python
- Pandas
- Scikit-learn
- Requests
- GitHub

How to Run:
1. pip install -r requirements.txt
2. python recommend_bus.py
